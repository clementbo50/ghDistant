Git et GitHub

Git est un système de contrôle de version distribué, tandis que GitHub est une plateforme d'hébergement pour les projets utilisant Git.

GitLab est une alternative à GitHub, offrant des fonctionnalités similaires avec un accent sur l'intégration continue et le déploiement continu (CI/CD).

Pour plus d'informations, consultez la documentation officielle de Git.
